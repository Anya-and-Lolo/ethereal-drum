COMMUNITY GALLERY
=================

Place approved .drumsong files in this folder and open the downloaded app with
the START_TRAINER launcher. The catalogue is rebuilt automatically. While the
starter remains open, added/moved/renamed/deleted songs are picked up and the
Community gallery updates live.

Website visitors cannot add files to this folder. They can prepare a song for
submission inside the app, then send the exported .drumsong file to the owner
through the contact method provided with the published website.
